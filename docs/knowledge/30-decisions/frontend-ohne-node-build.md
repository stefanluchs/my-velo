# Frontend ohne Node-Build

**Claim:** Das Frontend besteht aus Go-`html/template`, htmx, MapLibre GL und uPlot als ES-Module, ohne Node-Build-Kette.

## Kontext
Karten und Charts müssen zwangsläufig im Browser laufen; alles andere rendert der Server.
Node wird nur für Tests DOM-freier Module gebraucht, nicht für Builds.

## Entscheidung
Server-gerenderte Seiten mit htmx-Fragmenten; Bibliotheken vendored und direkt als
ES-Module importiert.

## Treiber
- Eine Toolchain (Go), Panel funktioniert ohne Internetzugang zum CDN.

## Verworfene Alternativen
- **SPA mit Node-Build:** zusätzliche Toolchain und Build-Artefakte für ein Ein-Nutzer-Panel.

## Konsequenzen
- Bibliotheken werden von Hand aktualisiert ([[vendor-bibliotheken-versioniert]]).
- htmx-Eigenheiten müssen bekannt sein ([[htmx-4xx-fragmente-swappen]]).

## Auswirkung auf die Implementierung
- Kein `package.json`, kein Bundler; neue Browserlogik als ES-Modul unter `internal/web/static/`.
