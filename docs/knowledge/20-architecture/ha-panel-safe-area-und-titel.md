# Home Assistant hält Safe-Area und Titel für das Panel frei

**Claim:** Im Ingress-Panel zeigt Home Assistant bereits Kopfzeile und Titel und polstert den Bereich der iOS-Home-Indicator-Leiste selbst (`hass-subpage` mit `padding-bottom: var(--safe-area-inset-bottom)`), deshalb darf das Panel unter Ingress weder eine eigene Titelzeile noch `env(safe-area-inset-bottom)` hinzufügen.

## Kontext
In `v0.7.0` erschienen in der iOS-App eine doppelte Kopfzeile („my Velo“ von HA und vom Panel) und
unter der Tab-Leiste ein leerer Streifen: Im iframe liefert `env(safe-area-inset-bottom)` trotzdem
einen Wert. Der dunkle Balken ganz unten gehört HA (Hintergrundfarbe des HA-Themes) und ist aus
dem Panel nicht steuerbar.

## Auswirkung auf die Umsetzung
- Der Server markiert Ingress-Seiten mit `data-embedded` auf `<html>`; CSS setzt dort `--safe-b: 0`.
- Unter Ingress keine Marke rendern; auf Handys gibt es keine Kopfzeile (`.topbar { display: contents }`),
  am Desktop nur die Navigation.
- Ohne Ingress (direkter Port) bleiben Marke und Safe-Area-Polsterung erhalten.
